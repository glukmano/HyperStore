# Implementation Phases

The **Hyper Commerce Platform** is engineered strictly phase by phase.

## Phase Governance Rules

1. **No Phase File = No Feature Coding**: Agents may only write feature code when an active, approved phase file exists in this directory.
2. **One Phase At A Time**: Work is scoped strictly to the current active phase.
3. **No Auto-Advancement**: Upon satisfying the phase Definition of Done, the agent must run all tests, generate a report, and STOP. It must never start the next phase automatically.
