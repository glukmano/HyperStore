# Architecture Proposals & RFCs

This directory stores proposals for modifying the architecture, extending invariants, or proposing revisions to [PROJECT_MASTER_PLAN.md](file:///Volumes/Lukman/dev/Projects/HyperStore/PROJECT_MASTER_PLAN.md).

## Proposal Rules (Master Rule 0)

If an architectural change appears necessary:
1. Create a proposal file in `docs/proposals/` using `RFC-0000-template.md`.
2. Detail the current rule, proposed change, reason, benefits, risks, migration impact, security impact, compatibility impact, and alternatives.
3. **DO NOT** implement the architectural change until the platform owner explicitly reviews and approves it.
